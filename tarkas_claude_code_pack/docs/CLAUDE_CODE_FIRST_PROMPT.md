# Primeiro prompt para Claude Code

Leia integralmente `CLAUDE.md`, `README.md` e os documentos relevantes em `docs/`.

Sua tarefa inicial é SOMENTE auditar o ambiente e o repositório. Não implemente player, DSP, IA ou integração de streaming ainda.

1. Verifique o diretório atual, estado do Git e arquivos existentes.
2. Não apague, mova ou sobrescreva trabalho existente.
3. Verifique disponibilidade e versões de Flutter, Dart, Java/JDK, Android SDK, adb e dispositivos/emuladores.
4. Execute `flutter doctor -v` se o Flutter estiver disponível.
5. Identifique bloqueios e recomende o próximo passo.
6. Se não existir projeto e as ferramentas estiverem prontas, proponha scaffold Flutter mínimo; crie-o somente depois de confirmar que o diretório está seguro para isso.
7. Não instale dependências, não baixe modelos e não crie contas/serviços pagos sem autorização.
8. Produza um relatório com: ambiente, comandos executados, resultados reais, bloqueios, riscos e próximo passo.

Ao final, atualize documentação apenas com fatos verificados. Não invente resultados. Aguarde aprovação antes de iniciar a fase seguinte.
